## ✨ Features

|   |   |
|---|---|
| 🎯 **맞춤 추천** | 관심 분야를 고르면 그에 맞는 논문만 골라 매일 아침 도착 |
| 📄 **깊이 있는 리뷰** | 초록만이 아니라, 방법론·실험·기여점까지 짚은 한국어 리뷰를 정독 |
| 🌐 **원문 ↔ 번역** | 영어 원문과 한국어를 한 번의 탭으로 오가며 읽기 |
| 🇰🇷 / 🇺🇸 **한 · 영 UI** | 앱 전체 언어 전환 (온보딩 · 설정) |
| 📚 **라이브러리** | 읽을 목록 · 저장 · 완료로 읽기 흐름 관리 |
| 📊 **주간 요약** | 이번 주 읽음 · 저장 · 연속 일수 · 주제 분포 |

## 📄 논문을 끝까지 읽게

초록만 훑고 닫는 대신, 논문 한 편을 제대로 읽을 수 있게 만든 리더입니다. 목차로 원하는 절을
바로 열고, 읽던 자리는 기억됩니다. 수식·표·아키텍처 다이어그램·그림이 모바일에서 무너지지 않게
각각 다르게 조판했습니다.
