## ✨ Features

|   |   |
|---|---|
| 🎯 **맞춤 추천** | 관심 분야·주기 기반 데일리 피드 |
| 🌐 **원문 ↔ 번역** | 영어 원문 ↔ 한국어 번역 토글 |
| 🇰🇷 / 🇺🇸 **한 · 영 UI** | 앱 전체 언어 전환 (온보딩 · 설정) |
| 📚 **라이브러리** | 읽을 목록 · 저장 · 완료 + 진행률 |
| 📊 **주간 요약** | 읽음 · 연속 · 주제 분포 |
